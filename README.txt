EXAMPLE HOTEL MASTER TEMPLATE

FILES
- index.html: one-page website structure and sample content
- style.css: dark luxury styling and responsive layouts
- script.js: mobile menu and automatic footer year

HOW TO RUN
1. Extract this folder.
2. Open index.html in your browser.
3. Internet is needed for Google Fonts and remote Unsplash sample photos.

BEFORE USING FOR A CLIENT
- Replace Example with the client's approved name and branding.
- Replace all sample images with approved photos you have permission to use.
- Verify room names, facilities, prices, amenities and descriptions.
- Replace the placeholder phone number in WhatsApp and phone links.
- Replace the generic Google Maps link and sample address with the verified listing.
- The sample WhatsApp number +250000000000 is deliberately not a real contact.
- The page does not have a booking engine or availability calendar; buttons link to contact options.
- Remove any amenities or claims the property does not provide.
- Customize for each client; do not deliver this unchanged.
